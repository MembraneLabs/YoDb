YoDb lets an app or an AI agent ask one question about data that lives in
several PostgreSQL databases. You do not write SQL, and your data is not copied
anywhere.

## The idea

A company's data is rarely in one place: customers in one database, billing in
a second, support tickets in a third. No single SQL query can reach all three.

With YoDb you describe the data once, in three YAML files called the *catalog*.
After that you query named datasets, such as `customer` and `ticket`, and YoDb
works out which databases to read, in what order, and how to join the answers.

A query is a small piece of JSON that names datasets and fields. It never names
a table and it is never SQL, so a caller cannot invent a join, write data, or
see how the databases are laid out.

## What it does

- **One dataset over several databases.** A dataset's fields can come from
  different PostgreSQL databases. YoDb assembles each record by its ID.
- **[Joins](/query/joins) across databases.** Follow a relationship you declared
  between two datasets, even when they are on different servers.
- **Filters, ordering and page size**, checked against the catalog before
  anything reaches a database. See [Query model](/query/query-model).
- **A [semantic filter](/query/semantic-filter).** A condition written as a
  sentence, judged by a model you supply, with a cost and time budget.
- **A plan you can read.** `yodb explain` shows which databases a query reads
  and what each one is asked. See [How queries are planned](/query/planning).
- **An [MCP server](/reference/mcp)** (`yodb mcp`), so an AI agent can discover
  and query a catalog with no SQL and no table names.
- **Read-only and bounded.** Every session is read-only, and every query has a
  time limit and row limits. See [Running YoDb](/operations/operating).

## What it does not do yet

PostgreSQL is the only supported database. There is no counting or totals, no
next page, and one join step per query. Read [Limits](/reference/limits) before
you rely on a query shape, and [Compatibility](/reference/compatibility) for
which parts are stable.
